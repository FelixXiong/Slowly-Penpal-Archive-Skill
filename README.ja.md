## この skill を作ったきっかけ
> 一人ひとりの文通相手とのつながりを、大切に残すために。

少しずつ途絶えていく文通もあれば、お別れが必要な相手もいます。

それでも、文通相手のリストを整理する前に、心を込めて書いた手紙や受け取った手紙は残しておきたいものです。

すべての手紙を PDF で保存した後、それらをどう整理し、一通ずつ読み返し、それぞれの文通を振り返ればよいのでしょうか。

Slowly のユーザーならご存じのとおり、Plus に加入していない場合、文通相手の枠は 100 人です。Slowly Plus の期限が切れ、更新しない場合には、相手のリストを整理する必要が生じることもあります。

そこで、この skill を作りました。

この skill は：
1. ウェブサイト上の手紙を代わりにダウンロードするものではありません。
2. 保存済みの手紙を、検索して読み返せるローカルのアーカイブに整理します。それぞれの文通を大切に保管できます。

現在は Slowly の手紙のアーカイブを対象としています。手紙を PDF に書き出せる他のアプリは未検証です。お試しいただいた際は、Issues でご報告いただけると幸いです。

## 事前準備
Slowly のウェブ版を開き、文通相手の手紙を自分で PDF として保存してください。相手ごとにフォルダーを作ります。例：

```text
手紙フォルダー/
└── 文通相手の名前/
    ├── Slowly.pdf
    ├── Slowly2.pdf
    ├── 切手/
    │   ├── 切手1.png
    │   └── 切手2.png
    └── プロフィール/
        └── アバター.png
```

注：手動で書き出したファイルとの互換性は、実際に確認する必要があります。

## 流れ
手紙を PDF で保存 → 相手ごとにフォルダーを作成（同じ相手の手紙はまとめる）→ 必要に応じて AI にファイル名の統一を依頼 → skill でアーカイブを生成 → 開いて読む。

## 使い方
1. skill の ZIP を展開し、`slowly-offline-archive` フォルダー全体を、使用するツールで設定された skills ディレクトリーに配置するか、そのツールのローカル skill インポート機能を使います。`SKILL.md` と `scripts/` を残してください。Markdown ファイルだけをコピーしないでください。
2. Skills に対応する業務ツール（WorkBuddy、千问办公、豆包工作）または IDE に、次のように依頼します。

> slowly-offline-archive を使って、（手紙の保存先パス）にある PDF をオフラインのアーカイブに整理してください。元のファイルは残し、生成後にアーカイブの入口を開いてください。

手紙を追加する場合：

> Slowly のオフラインアーカイブ skill を使ってください。資料ディレクトリーは（手紙の保存先パス）です。既存のアーカイブに新しい手紙を追加してください。

初回実行には Python を実行できるホスト環境が必要です。`pypdf` がない場合、AI がその環境で許可された方法で対応します。

依存パッケージを初めて取得する際は、インターネット接続が必要になることがあります。アーカイブの作成・閲覧時には Slowly にアクセスしません。

生成後は、ローカルの `index.html` を開くだけで読めます。その後、AI やローカルサービスを起動し続ける必要はありません。

## 生成されるファイル

| ファイル | 用途 |
| --- | --- |
| `index.html` | 直接開けるオフラインアーカイブ |
| `slowly_pdf.db` | 手紙のデータベース |
| `letters.jsonl` | 構造化された手紙のレコード |
| `build.json` | インポート統計、失敗の記録、確認待ちの件数 |
| `media.json` | ローカルの画像・テキストと関連付けのインデックス |

## データの安全性
この skill 自体はインターネットに接続せず、Slowly のウェブページを自動操作したり、ログイン状態を読み取ったりしません。Slowly へのログインも不要です。保存済みの手紙 PDF だけを読み込み、`pypdf` で本文を抽出します。そして、検索可能な SQLite データベースと、データを埋め込んだ単一ファイルのウェブアーカイブを生成します。アーカイブはダブルクリックで開けます。

依存パッケージ：`pypdf`。初回インストール時は、ダウンロードのためにインターネット接続が必要です。

## よくある質問
**Q：手紙の保存フォルダーを変更した場合は？**

A：IDE または WorkBuddy に戻り、AI に新しいパスを伝えて再生成してください。
